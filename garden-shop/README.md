# Garden Shop

This is a small full-stack project (client + server). This README contains quick instructions to initialize a local git repository and push it to GitHub.

Quick start

1. Install dependencies for both `client` and `server` as needed.
2. Create a local `.env` from `.env.example` in `server/` and fill secrets.
3. Start the apps (e.g. `npm run start` or `npm run dev`).

Initialize git and push (example)

See the instructions in the project root for commands to create a GitHub repository and push your code.
